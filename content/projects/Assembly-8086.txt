Lesson 2 - Basics... The Mysteries of the CPU!:

[text]
Accumulator Register (A):

[code]
LD A,5      ; A = 5
ADD A,8     ; A = A + 8

[text]
Keep in mind:

[code]
LD A,5
LD B,8
ADD A,B

[text]
Result:

[code]
A = 13
B = 8

[text]
Notice the result must go into A.

[text]
Why on this case the Z80 have one accumulator register (A) and not two (A and B)?

[text]
Because the hardware was simpler.
[text]
if you build the CPU from logic gates, it's much easier to design one adder whose output always goes back into A.
[ascii]
           +---------+
A -------->|         |
           |   ALU   |-------> A
B -------->|         |
           +---------+

[text]
The ALU (Arithmetic Logic Unit) takes inputs, performs the operation and wires the output back into A.
[text]
To let every register be both an input and output would require more multiplexers, control logic and wiring.

[text]
Program Counter Register (PC) / Instruction Pointer (IP):

[image]
src: /content/gallery/upload/Asm_P/PC.png
alt: PC Image Description
caption: The Program Counter Register (PC) / Instruction Pointer (IP) holds the address of the next instruction to execute.

[text]
Suppose your program is stored in memory and the memory looks like this:
[ascii]
Address      Instruction
-------      ----------------
1000         LD A,5
1002         ADD A,3
1004         SUB A,1
1006         HALT

[text]
Instructions live in memory just like data.

[text]
Every clock cycle CPU wants to know which instruction to execute next. the answer to this question is stored in the PC register.

[text]
At the beginning of the program, the PC is set to the address of the first instruction.
[code]
PC = 1000
[text]
Step 1
[text]
CPU reads the instruction at PC = 1000:
[code]
Memory[1000] = LD A,5
[text]
It executes the instruction:
[code]
LD A,5
[text]
Then it increments PC to point to the next instruction:
[code]
PC = 1002

[text]
Flags Register / Condition Codes:

[image]
src: /content/gallery/upload/Asm_P/FR_CC.png
alt: Flags Image Description
caption: The Flags Register / Condition Codes hold the results of the last operation.

[text]
If you calculate something like 5 - 5 = 0, the result is stored in the A register (usually) and the zero flag (Z) is set.

[ascii]
+------------------------+
| Z | C | V | N | ...    |
+------------------------+
| 1 | 0 | 0 | 0 | ...    |
+------------------------+

[text]
Flag registers storing yes/no answers to questions about the last operation.

[text]
Zero Falg (Z):
[text]
Question: Was the result zero?
[code]
LD A, 5
SUB A, 5
[text]
The CPU computes:
[code]
5 - 5 = 0
[text]
Now:
[code]
A = 0
Z = 1 ; The answer is zero, so Z is set.
